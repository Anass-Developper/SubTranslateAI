# Roadmap

This roadmap communicates direction, not guaranteed release dates.

## Near term

- publish the extension through the Chrome Web Store and Microsoft Edge Add-ons;
- add compatibility fixtures for supported video platforms;
- sign Windows installers when sustainable;
- improve first-run hardware guidance and performance estimates;
- build a reproducible, legally shareable FR/ZH/EN subtitle evaluation set.

## Later

- optional local speech-to-text when no subtitle track exists;
- additional languages after measurable quality evaluation;
- easier contributor tooling for new website adapters;
- accessibility and keyboard-navigation improvements.

Requests are welcome, but privacy, subtitle synchronization and translation quality take priority over feature count.
